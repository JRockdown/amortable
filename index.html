Lease Builder

Lay out the cash flows of a lease, in date order. Give any line a code (like OEC) and reuse it elsewhere — a residual of 0.15 x OEC updates itself. Put X in one or more amounts (or in the rate) and Solve fills it in.

Set each line's own periodicity in the Per column. Drag ⠿ or use ↑ ↓ to reorder, then Re-chain dates to space them by ×N. Money out is red (－), in is green (＋). Tick no interest for pass-through fees (e.g. service). Add a Rate change line (a date + a new rate) for a stepped/floating rate.

Solve any of the five: N, rate, present value, payment, future value. Money received +, money paid −.
