# Amortable

A client-side time-value-of-money workbench — TVM solver, amortization schedules
(with variable-rate ARM-style recasts), and cash-flow NPV/IRR analysis with dated
day-count XNPV/XIRR and solve-for-unknown. Pure static `index.html`, no build step.

**Deploy (Cloudflare Pages):** Framework preset **None**, Build command **(empty)**,
Build output directory **/**.
