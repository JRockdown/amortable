Lease Builder

Lay out the cash flows of a lease, in date order. Give any line a code (like OEC) and reuse it elsewhere — a residual of 0.15 x OEC updates itself. Put X in one or more amounts, in the rate, or in a line's ×N (to solve the number of payments) and Solve fills it in.

🖱️ Built for locked-down browsers: tap any field to enter values with the on-screen keypad — no typing needed. Buttons and dropdowns work as normal.
Set each line's own periodicity in the Per column. Drag the ⠿ handle to reorder, then Re-chain dates to space them by ×N. Money out is red (－), in is green (＋). Tick no interest for pass-through fees (e.g. service). Add a Rate change line (a date + a new rate) for a stepped/floating rate.
↻ Inputs changed — click Solve / Analyze to refresh the results.
